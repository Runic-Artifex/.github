# Runic Artifex

Runic builds NativeAOT-minded tools for modern .NET applications, with typed
application logic, web frontends and native desktop integration.

Runic SDK products each own their source, documentation, and releases:

- [**Runic SDK**](https://github.com/Runic-Artifex/runic-sdk) — application
  framework, desktop host, assets, frontend integrations and examples.
- [**Runic CLI SDK**](https://github.com/Runic-Artifex/runic-cli-sdk) — the
  Runic Command Line framework and generator.
- [**Runic Translations SDK**](https://github.com/Runic-Artifex/runic-translations-sdk)
  — translation runtime and tooling, plus the Translations Editor.

- [Examples and migration from WPF/CommunityToolkit MVVM](https://github.com/Runic-Artifex/runic-sdk/tree/main/examples)
- [Documentation](https://docs.runic-artifex.eu/)
- Report issues in the tracker for the owning product repository.

[CS-WebUI](https://github.com/Runic-Artifex/cs-webui) remains the independent native
WebUI binding. [Runic Brand](https://github.com/Runic-Artifex/runic-brand) owns shared
visual assets, and [Runic Site](https://github.com/Runic-Artifex/runic-site) owns the
marketing website. Organization governance and release policy live in this repository.

The earlier monorepo cutover record remains available in the
[Runic SDK repository](https://github.com/Runic-Artifex/runic-sdk/blob/main/eng/migration/github-cutover.md).
Runic Flow and Runic Markup remain separate legacy products.
