# Support

Report SDK defects and feature proposals in
[runic-sdk issues](https://github.com/Runic-Artifex/runic-sdk/issues), including
issues involving packages whose former repositories have been archived.

Use repository discussions for design and usage questions when enabled. Use an
issue for reproducible defects or concrete feature proposals. Security reports
must follow `SECURITY.md`.

Before requesting help, include the package and version, operating system,
runtime, a minimal reproduction, and the complete relevant diagnostic output.
